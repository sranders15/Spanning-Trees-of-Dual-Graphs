# Spanning-Trees-of-Dual-Graphs

This repositopry accompanies the paper "Census Dual Graphs: Properties and Random Graph Models" by Sara Anderson, Sarah Cannon, Brooke Feinberg, and Anne Friedman. Other experiments in this paper (in particular those considering random point cloud-based randomg raph models) are available at https://github.com/afr13dman/senior-thesis. 

Real-world experiments using Census dual graphs at the county, tract, block group, and block level are based on dual graphs provided by Daryl DeFord, from shapefiles available on Redistrcting Data Hub.  These graphs themselves are not included in this repository due to their size but are available upon request (to scannon@cmc.edu).


## Graph Properties/

Computes and visualizes some basic properties of dual graphs, including the spanning tree count.

## Perturbing Grids/

Compares to the number of spanning trees of real-world dual graphs to those of square and triagular grids, as well as random grids that interpolate between the two.

## Splittability/

Experiments estimating the probability a random spanning tree of real-world dual graphs is splittable into balanced pieces
