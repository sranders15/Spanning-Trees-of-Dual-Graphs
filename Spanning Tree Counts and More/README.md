# Spanning Tree Counts and More

`Graph Properties.py`: For all census graphs at the tract, block group, or block level, compute all relevant statistics related to conenctivity, planarity, degree, and spanning tree count. 

`t_stats.csv`: All computed statistics for tract graphs. The final two rows compute the means and medians of these various quantities. 

`bg_stats.csv`: All computed statistics for block group graphs. The final two rows compute the means and medians of these various quantities. 

`b_stats.csv`: All computed statistics for block graphs. The final two rows compute the means and medians of these various quantities. 

`Graph Visualizations.py`: For census graphs at the tract, block group, or block level, visulize the relationships between spanning tree counts, spanning tree constant (ln(N_{ST})/n), and number of vertices.

`fig/`: The figures created in `Graph Visualizations.py`
